# 方案单页复用与编辑交互（2026-09-03）

## 用户确认的边界

在方案 A 编辑过程中，选择**已保存方案 B 的某一页**，把它连同绑定配置插入 A。不是重新载入整个方案 B，也不是只从 PPT 文件导入一张空白配置页。保持现有导入不同 PPT、新增报告页的入口。

## 操作

1. 编辑台左侧「报告页面」→「从其他方案插入页面」。
2. 选来源方案、方案内页码、插入位置（当前页后 / 报告末尾）。右侧按来源绑定与当前数据预览；未填写数据和预览错误会提示。
3. 「插入这一页」创建独立副本并切换到它。包含源模板 ID、源页码、所有绑定及 options、images、repeat、condition。浏览和取消不改变当前报告；来源方案不被写入。
4. 可重复插入同一页，分别编辑；用「上移 / 下移」调整报告页序。完成后保存**当前方案**。保存方案名称仍由用户决定，复用操作不会自动覆盖任何方案。

选择公式对象后进入中文公式编辑器：搜索参数名，点击文字/分子/分母后插入参数；支持文字段、分式、常用运算符及上下标字符，按当前数据预览。旧 `options.template` 自动转成中文参数显示，保存时还原原兼容格式。

公式编辑器是**显示编排器**，不增加任意表达式计算能力、不运行代码；胀型力、锁模力等仍由现有 FastAPI 计算。未知旧路径保留为「其他已绑定参数 N」。缺参数提示补数据；分式缺项、中文参数标签损坏会阻止保存。

对象可从画布选择，也可搜索名称/原文后从列表选择（显示类型、ID、单元格行列和绑定状态）。画布支持 Enter/空格选择；默认适应宽度。绑定区显示保存状态，切换对象或报告页保留本次未保存草稿，可「撤销未保存修改」。生成/保存方案前需先保存或撤销草稿，防止误以为修改已生效。草稿仅本次页面会话保留，刷新前应保存绑定。

## 开发文件与接口

| 文件 | 职责 |
| --- | --- |
| `static/template_editor.html` | 现有入口；页面列表、弹窗壳、绑定面板钩子、样式；DOMContentLoaded 后初始化 |
| `static/editor_ux.js` | 方案读取/单页预览/独立插入；对象导航；公式 GUI；草稿与撤销 |
| `static/editor_models.js` | 可在 Node 测试的纯模型：深拷贝插页、中文参数双向映射、公式分段序列化 |
| `app/main.py` | 新增 `POST /api/template/formula-preview`，沿用数据上下文与公式 PNG 渲染器 |
| `tests/editor_models.test.cjs` | 深拷贝隔离、重复插页、非法位置、旧公式往返、重名/未知参数、无效分式 |

复用无需新增写接口：读取 `GET /api/schemes` 和 `GET /api/schemes/{name}`，先 inspect/scan 检查源页，再调用已有 `POST /api/template/live-preview`。确认前的异步请求使用版本号/取消保护；确认时使用已获取元数据，不等待外部请求，避免半完成状态。

`_editorId` 是页面实例 ID，仅用于浏览器草稿隔离，不写入服务器方案 schema。同一源页被多次复用时不共享绑定对象或草稿。`serializeDeckPage` 保留旧 `images` 配置。跨模板页沿用现有 `state.baseTemplate` + 逐页 `template` 生成机制。

公式预览请求：`{expression: 'F = [[{ppt.force.area_part}|10]]', data: {f,t,i}}`。成功返回 `image/png`、`Cache-Control: no-store` 和 `X-DFM-Formula-Missing`；空公式、超长公式、无效分式、对象/图片参数返回 422。与 PPT 使用同一 `render_data_template` / `render_formula_png` 路径。

## 验证及保留限制

- Python 全量 172 项通过；Node 纯模型 6 项通过，含跨模板生成既有回归。
- 浏览器实测：插入保存方案一页（10 处绑定），原报告页（9 处）保留；中文公式加载/预览/插入参数、保存刷新、切换对象草稿、撤销、空分母校验、页面排序和移除测试副本。
- 未覆盖四份现有服务器方案；验证前后 SHA256 一致。测试副本已从当前报告移除。
- 真实页面 PNG 仍依赖 Windows PowerPoint COM；公式单独预览不依赖 COM。预览失败不会假装生成成功，元数据有效时仍允许插入。
- 不同尺寸来源会提醒核对导出版式；现有正式 84 页 A12 跨文件拼接的 PowerPoint 兼容性限制未由本次前端改动解决，见旧交接 §4。
- 局部文字替换、缺图片保留原对象、原样模板预览均沿用原逻辑；没有重新绘制 PPT 页面。
- 小屏做了自适应布局，但此次真实浏览器验收为桌面视口，移动端完整操作仍需专项验收。
