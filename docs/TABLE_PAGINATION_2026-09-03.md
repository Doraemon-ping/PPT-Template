# 表格自动分页、统一数据行与兼容性修复

## 使用

- 已有 `table_rows` 整表绑定默认启用，无需重新保存旧方案。
- 保持原表格起点、列宽、表头和页面标题；按原表格区域、页面底边以及数据文字估算容量，装不下则复制来源页接着填。
- 默认样式参考行：表头之后第一行。整表列对应面板可以选「样式参考行」和「每页数据行数（不含表头）」；条数留空自动计算。
- 填写 N 时，将原表格数据区域等分为 N 行，并按 N 条分页；不再仅作自动容量的上限。因此调大或调小行数都会生效。保持原字号，文字放不下时明确提示可容纳上限，不静默改回自动条数。
- 所有绑定数据行使用同一参考行的字体、段落对齐、边距和统一高度；自动模式下，长文本按最需要空间的记录统一增高，减少每页条数。最后一页只保留实际数据行，不拉伸填满剩余空间。
- 再次选中已绑定整表直接回显配置（按 shape_id 匹配，兼容旧绑定键）；更改行数或列对应后点击「保存表格配置并预览」。未保存的整表修改纳入草稿和生成/保存方案拦截，切换对象后可以恢复。
- 预览上方「生成续页」可查看第 1 / N、2 / N 等页。生成行数变化后，隐藏原模板单元格命中框，以免旧格线叠在真实表格上。整表对象仍可选择配置；查看原模板模式仍可选原始单元格。

## 模型与代码

`app/report/ppt/openxml/table_pagination.py` 在填写任何 OOXML 前，读取原表格与每个 repeat item 的数据，计算分页切片。切片放在运行时 `SlideOp.table_data`，不写方案，也不改输入数据。每条数据仅写一次；多个整表绑定按各自分页并行推进，已用完的表格仅保留表头。

`shape_binding.py` 接受统一行高/样式参考行参数，复制参考行样式并移除数据区合并，保留表头合并；空单元格插入文字时继承 `endParaRPr` 字体。不绑定的列仍保留其原单元格内容，不擅自覆盖。

绑定 options：

```json
{"start_row":1,"style_row":1,"rows_per_page":0,"paginate":true,"columns_map":{"0":"name","1":"ver","2":"state","3":"remark"}}
```

行号在 API 内为 0-based，界面为 1-based。`paginate` 默认 true；false 仅用于调用端显式选择旧增删行行为。`rows_per_page=0` 自动，正整数控制每页数据行数并等分数据区高度，不会允许文字超出可用区域。显式行数语义已由“容量上限”修正为“指定排版行数”；历史方案如存了非零值，也按指定行数执行。

`POST /api/template/live-preview` 新增 `page` 请求参数（默认 1）；响应头 `X-DFM-Preview-Pages`、`X-DFM-Preview-Page` 返回续页总数和当前页。预览仍用原地填写临时文件、仅首个 repeat item；选择过期页码会回落到最后一页。

导出使用 `deck` 生成续页。显式请求 `in_place` 且内容需要续页时会报错提示切换 deck，避免悄悄丢掉超出数据。

## PowerPoint 兼容性：本次实际定位

1. 同模板复制：**页面标签 tags part 不能在不同页面间共用**。`clone_slide` 为每个副本单独复制 tags，不能像图片/布局一样共享。
2. 跨模板导入：tags 不允许按内容哈希去重；母版和版式 ID 必须避免与现有模板碰撞。`SlideImporter` 为新导入母版/版式分配唯一 ID，并跳过最终不用的 notesSlide 递归回链。
3. 原有 rebuild 会删除 notes；现在同步删除指向这些已删除 notes 的关系和失效 Content Types，避免悬空引用。未新增删除用户源文件行为，源模板不写入。
4. PowerPoint COM 集合访问改用反射，避免本机 Interop 偶发返回 null；导出脚本错误明确返回失败，日志解码容忍非 UTF-8 输出。

## 明确限制

- 换行高度是根据字号、列宽、边距、行距的保守估算，不是完整 Office 字体排版器。特殊字体/复杂多段文字仍需最终预览核对。
- 单条记录连一页都放不下会报错要求拆分/缩短，不自动截断文本或缩小字号。
- 保留原表格可用区域，不将模板中的所有空白自动扩成表格。为了统一行高，某些非等高/合并的模板每页可装条数会减少。
- 上述两个真实样本已验证，不等于所有正式 84 页模板、图表/OLE 组合都完成兼容性验收。
