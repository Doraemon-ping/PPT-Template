连接信息

同一系统的多个接口共用这里的 Base URL 和认证。例如 https://api.company.com/dfm + bearer token，接口只需写自己的相对路径。

显示在工作空间「数据来源」和绑定编辑台里的名字，填业务名称即可。
Dataset 的 source 标识，用于按来源查历史数据；建议全工作台唯一，创建后尽量不要再改。
只写「协议 + 主机 + 公共前缀」，例如 https://api.company.com/dfm；下面接口的 Path 里不要再重复这段地址。
决定下方「认证配置」要填哪些键：none 留空 / bearer 用 token / basic 用 username、password / api_key 用 name、key、location。
单次取数的等待上限（1–300 秒）；报表类接口较慢时可调到 60。
高级认证配置 JSON
按上面选的「认证类型」照抄一种即可
  • none：留空或 {}
  • bearer：{"token_env":"DFM_API_TOKEN"}；没有环境变量就直接写 {"token":"eyJhbGci..."}
  • basic：{"username":"report","password_env":"DFM_API_PASSWORD"}，也可以用 password 写明文
  • api_key：{"name":"X-API-Key","key_env":"DFM_API_KEY","location":"header"}；密钥放在 URL 参数上时把 location 改成 query
带 _env 后缀的键会去读同名环境变量，推荐用它保存密钥，避免明文入库；填错时「5 测试」会提示认证失败。

一个连接下可以建多个分类接口（问题列表、工序数据…）。Path 用 {参数名} 占位，由第 3 步的同名 path 参数替换。

查询数据用 GET；只有 POST 才会发送下方的 Body Template。
停用后「刷新全部数据」会跳过该接口；调试期间可以先停用。
Base URL 之后的相对路径，不要写主机；{project_id} 这类占位符必须和第 3 步同名的 path 参数配对，否则执行时会提示「路径存在未配置的 path 参数」。
高级请求配置 Header / Query / Body
三块都留空也能工作，按需补
  • Headers：固定请求头，例如 {"Accept":"application/json","X-Tenant":"hpm"}；认证头由「连接」自动附加，不用写在这里。
  • Query：固定查询串，例如 {"pageSize":200}；需要动态值时，在第 3 步建同名 query 参数覆盖。
  • Body Template：POST 的 JSON 骨架，例如 {"projectId":"","page":{"size":200}}；第 3 步 body 参数名写 page.size 就能改到嵌套字段。
键和值都按字符串发送。
会拼到 URL 上，数字、布尔值可以按 JSON 原样写。
只有 Method 为 POST 时才发送；留空表示发送 {}。

请求参数

外部接口需要的动态值逐条登记。示例：参数名 project_id、Location path、Source input、Source Key project_id，再在第 5 步执行时传 {"project_id":"P-2026-001"}。接口不需要参数时这一页可以跳过。

请先选择接口
path / query / header 用外部接口的真实参数名；body 参数名支持 page.size 这类嵌套路径，会写到 Body Template 的对应位置。
这个值放在请求的哪里；选 path 时接口 Path 里必须有 {同名占位符}。
input = 执行时由 Runtime Parameters 传入（如 project_id）；context = 执行时由 Context 传入（如 tenant）；fixed = 恒定值，直接写 Default。
从 input / context 里取值的键，支持 a.b 逐层取；选 fixed 时这一项会禁用。
取不到值时的兜底值，选 fixed 时必须填。按 JSON 写：字符串带引号 "P-2026-001"、数字 30、布尔 true。
